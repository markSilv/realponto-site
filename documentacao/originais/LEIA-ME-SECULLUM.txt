COMO APLICAR — ATUALIZAÇÃO LEVE (RECOMENDADA PARA O SITE EXISTENTE)
1. Faça uma cópia de segurança da pasta original do site.
2. Extraia RealPonto-Atualizacao-Secullum.zip.
3. Copie os arquivos e pastas extraídos para a RAIZ do seu site, onde fica
   o index.html. Mescle as pastas css, js e img e substitua os arquivos
   de mesmo nome. Não apague os demais arquivos ou pastas.
4. Abra sistema-secullum.html, ou acesse Sistemas de ponto > Secullum RH.
5. No servidor, envie os mesmos arquivos mantendo os caminhos das pastas.
   Após publicar, recarregue com Ctrl+F5 para evitar o cache antigo.

OBSERVAÇÕES
Esta entrega contém arquivos para você publicar: não houve alteração da
hospedagem ou implantação no servidor. A demonstração não é o sistema
Secullum real: não faz login, não salva marcações e não usa dados de clientes.
As imagens representam a versão Pro fornecida; recursos e contratação
devem ser confirmados pela RealPonto.
Os links externos e serviços de terceiros já existentes foram preservados;
a disponibilidade desses serviços não foi validada nos testes locais.
